# 演示素材C：基于图的索引机理

基于图的索引把每个向量作为图中的节点，并为每个节点保留若干条指向相近向量的边。查询时从入口节点出发，沿着距离查询向量更近的邻居不断跳转，直到无法找到更近的节点为止。

分层可导航小世界图（HNSW）在此基础上引入多层结构：上层图稀疏，用于快速逼近目标区域；底层图稠密，用于精细搜索。参数 M 控制每个节点的最大连接数，参数 efSearch 控制查询时的候选队列大小。

efSearch 越大，访问的候选越多，召回率越高，但延迟也随之上升。M 越大，图的连通性越好，但内存占用和构建时间同步增加。

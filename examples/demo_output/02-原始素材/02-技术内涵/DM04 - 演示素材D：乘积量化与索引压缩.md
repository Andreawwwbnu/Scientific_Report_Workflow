# 演示素材D：乘积量化与索引压缩

乘积量化把高维向量切分为若干个子向量，并对每个子空间分别训练一个包含 256 个中心点的码本。每个子向量只需记录最近中心点的编号，因此一个 128 维的浮点向量可以被压缩为 16 字节的编码。

压缩使得十亿级向量可以放入有限内存，代价是距离计算变为近似值，召回率会下降。实践中常与倒排索引结合：先用聚类缩小候选范围，再用压缩编码计算近似距离，最后对少量候选用原始向量重排序。

重排序步骤能够显著恢复精度，是在内存与召回率之间取得平衡的常用手段。
